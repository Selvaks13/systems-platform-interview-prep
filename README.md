# Systems & Platform Engineering Interview Preparation

A 16-week, project-driven preparation repository for Senior Software Engineer roles in systems, platform, infrastructure, networking and AI infrastructure.

## How to use this repository

1. Follow [ROADMAP.md](ROADMAP.md) for the 16-week sequence.
2. Use the topic folders for concept-by-concept learning.
3. Update checkboxes as you work. Do not mark a topic complete just because you read it.
4. Record implementations and problem-solving evidence in `coding-practice/` and `projects/`.
5. Review `PROGRESS.md` every Sunday.

## Completion standard

A topic is **Completed** only when you can:
- Explain it without reading notes.
- Implement or demonstrate it independently.
- Discuss edge cases, trade-offs and failure modes.
- Answer representative interview questions.

## Suggested status labels

- `[ ]` Not started
- `[/]` In progress (use this marker in notes if desired)
- `[x]` Practised and completed
- `[!]` Needs revision

GitHub Markdown checkboxes are the source of truth for individual items. A GitHub Projects board can provide a cross-topic overview.

## Preparation priorities

- Modern C++ and DSA: continuous practice across all 16 weeks.
- OS/Linux and networking: build strong systems fundamentals.
- AWS, Docker and Kubernetes: learn by deploying working services.
- System design: practise trade-offs and failure scenarios.
- AI infrastructure: build and evaluate a practical RAG/document assistant.

## Repository structure

- `topics/`: separate syllabus and resource links for each subject.
- `projects/`: project specifications and implementation milestones.
- `coding-practice/`: DSA and C++ exercises.
- `interview-notes/`: mock interviews, behavioural stories and design notes.
- `weekly-reviews/`: weekly evidence, gaps and next steps.
