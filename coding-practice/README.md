# Coding Practice

For every problem, record:
- Problem and link
- Pattern / data structure
- Initial approach and improved approach
- Time and space complexity
- Edge cases
- Can I solve it again without hints? (yes/no)
- Revisit date

Target roughly 110 carefully reviewed problems across arrays/strings, hashing, two pointers, sliding window, binary search, linked lists, stacks/queues, trees, heaps, graphs and DP. Understanding and independent re-solving matter more than raw count.
