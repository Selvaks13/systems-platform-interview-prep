# Core Free / Open Learning Resources

Start with authoritative documentation and widely used references. Do not purchase courses immediately. Add a paid course only if a specific learning gap remains after using these resources.

| Subject | Primary resource | Reference / practice |
|---|---|---|
| Modern C++ | [LearnCpp](https://www.learncpp.com/) | [cppreference](https://en.cppreference.com/w/) |
| DSA | [LeetCode](https://leetcode.com/) | [NeetCode](https://neetcode.io/) |
| Operating Systems | [OSTEP](https://pages.cs.wisc.edu/~remzi/OSTEP/) | Course notes and exercises |
| Linux | [Linux man-pages](https://man7.org/linux/man-pages/) | `man`, `strace`, `gdb`, `perf` |
| Networking | [Beej's Guide](https://beej.us/guide/bgnet/) | [RFC Editor](https://www.rfc-editor.org/) |
| System design | [System Design Primer](https://github.com/donnemartin/system-design-primer) | Architecture case studies |
| AWS | [AWS Skill Builder](https://skillbuilder.aws/) | [AWS Documentation](https://docs.aws.amazon.com/) |
| Docker | [Docker Get Started](https://docs.docker.com/get-started/) | [Docker documentation](https://docs.docker.com/) |
| Kubernetes | [Kubernetes Tutorials](https://kubernetes.io/docs/tutorials/) | [Kubernetes documentation](https://kubernetes.io/docs/home/) |
| LLMs | [Hugging Face Learn](https://huggingface.co/learn) | [Attention Is All You Need](https://arxiv.org/abs/1706.03762) |
| RAG | [DeepLearning.AI short courses](https://www.deeplearning.ai/short-courses/) | Framework documentation and evaluation papers |

## Resource selection rules

1. Prefer official documentation for APIs, configuration and operational behaviour.
2. Use a structured tutorial to build the mental model.
3. Use exercises to test understanding.
4. Keep one primary resource and one reference resource per topic; avoid collecting endless links.
5. Record the exact page or chapter used in the topic file.
